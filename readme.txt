LeTx Esports — сайт команды CS2

Файлы:
- index.html — структура и тексты сайта
- style.css — дизайн, адаптация под телефон
- script.js — мобильное меню и год в подвале
- assets/letx-logo.png — временно вырезанная эмблема из созданного баннера

Как опубликовать бесплатно через Netlify:
1. Распакуйте ZIP на компьютере.
2. Откройте https://app.netlify.com/drop
3. Перетащите туда папку letx_esports_site (или сначала перетащите ZIP, если интерфейс это предлагает).
4. Netlify выдаст публичную ссылку на сайт.
5. Для изменения сайта отредактируйте файлы и загрузите обновлённую папку снова.

Перед публикацией:
- Замените временный assets/letx-logo.png на исходный логотип команды (сохраните то же имя файла).
- Обновите карточки состава, когда будут готовы никнеймы игроков.
- Добавьте ссылки на соцсети и точные данные турнира, когда они появятся.

Сайт статический — сервер или база данных не нужны.
